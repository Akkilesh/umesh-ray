# Srishti Ray — Digital Business Card

Updated to use the RealSell brand palette from the supplied reference:
- Deep Navy `#0A1B33`
- Royal Blue `#1E5BFF`
- Silver `#B7BDC6`
- Light Gray `#E6E8EC`
- White `#FFFFFF`

## Preview locally
Open `index.html` in a browser. Internet access is needed for Bootstrap 5 and Bootstrap Icons CDN assets.

## Before publishing
1. Replace LinkedIn, Instagram and Facebook links with Srishti's actual profile URLs.
2. Confirm the email spelling and website domain with the client.
3. Upload to a static host (for example, GitHub Pages, Netlify, or Vercel).
4. Point the printed QR code to the final published HTTPS URL.

## Features
- Bootstrap 5 responsive layout
- Save Contact downloads a `.vcf` contact file
- Share Profile uses the native share sheet where supported, otherwise copies/prompts for the URL
- Tap-to-call, email, website, map and WhatsApp links

The page currently uses an initials avatar (SR) because no portrait photo was supplied.
